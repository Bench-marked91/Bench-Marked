The Problem

Keeping Up by Hand
Is Impossible

📄
New papers appear constantly
Mental-health AI is one of the fastest-growing research domains — hundreds of new arXiv submissions every month.
⏱️
Manual reading doesn't scale
Reading, filtering, and cataloging papers by hand is time-consuming, inconsistent, and prone to gaps.
🗂️
We need a current, trustworthy, browsable catalog
The field needs a living reference — not a stale spreadsheet or a once-a-year literature review.

"The field moves fast; keeping up by hand is impossible."

The Core Idea

Automation does the heavy lifting.
People make the judgment calls.

Architecture Overview

Two Loops, One Human Gate

🔍 Loop A — Discovery
01 Find papers on arXiv
02 AI filters relevance
03 AI extracts catalog fields
04 Drops to AI Inbox sheet
🔒 Human Gate
Review Inbox → Promote good rows → Master Catalog
Add quality grades — AI leaves these blank
🚀 Loop B — Publish
Master Catalog → data file → Website

"Two automated loops with a human approval step in the middle."

🔍 Loop A — The Discovery Robot

Cheap AI screens.
Smart AI does careful reading.

📡
Searches arXiv for new papers
No AI needed for discovery — free API, runs on schedule
⚡
Claude Haiku labels relevance
Cheap, fast triage: Definitely / Might-be / Not
🧬
Claude Sonnet reads PDFs & extracts fields
Smart AI reads the full paper and structures catalog data
📥
Results land in AI Inbox, marked "New" — no duplicates ever
Robot remembers every paper it has seen using a persistent seen-IDs log
🔒 The Human Approval Gate

The robot proposes.
We decide.

What the robot does
  • ✓ Writes to AI Inbox only
  • ✓ Extracts metadata fields
  • ✗ Never touches Master Catalog
  • ✗ Never fills quality grades
What the human does
  • ✓ Reviews Inbox rows
  • ✓ Promotes good ones → Master Catalog
  • ✓ Adds rigor grades (AI leaves blank)
🧑‍⚖️

Nothing goes "official" or public without a person reviewing it first. This is our quality control checkpoint.

"This is our quality control — the robot proposes, we decide."

🔐 Security

Credentials are locked down
and never exposed.

🔒
Secrets stored encrypted in GitHub
AI key, Google service account key, and Sheet ID all live in GitHub Secrets — never in the codebase
⚡
Robot's key is used at runtime, then deleted
Credentials are injected at execution time as environment variables and not persisted anywhere
🛡️
Repo is private; sensitive files are .gitignored
Private repository + .gitignore rules block credential files from ever being committed or uploaded
